# 来源与贡献边界

本项目在 [xinconner/shopping-agent-ai](https://github.com/xinconner/shopping-agent-ai) 基础上进行二次开发，感谢原作者 xinconner 提供的商城与 AI 购物助手基础。本仓库地址为 [Huagexinn/shopping-agent-plus](https://github.com/Huagexinn/shopping-agent-plus)。

2026-11-27 核对上游公开 README：基础项目已有商城业务、Spring AI 原生工具调用、SSE、混合 RAG、Redis 记忆，以及用户确认/支付的基本边界。因此本项目的贡献应描述为可靠性、确认闭环和工程评价的增强，不能写成从零实现全部商城或首次引入这些能力。

| 上游已有基础 | 本 Fork 三项改造的增量 |
|---|---|
| 商品、购物车、订单、登录及前后端页面 | 复用基础业务，补齐跨重试请求身份、数据库级幂等及可核实结果 |
| 工具调用审计、基础幂等约束 | 任务/步骤持久化、断线查询、业务记录对账、按原参数受控恢复 |
| 订单预览、用户确认下单、模拟支付 | 将预览持久化到 MySQL，绑定原快照及确认指纹，锁定重校验、原子提交、刷新查回与重复确认回放 |
| 基础测试与工具策略 | 版本化任务场景、跨表判定器、评分负对照、隔离实验、指标与基线报告 |
| 原有事实校验器 | 通过场景评测发现并修复明确库存拒绝回复被误判的问题 |

“原有问题”指本次改造起点的实现所暴露的场景缺口，不表示上游当前版本永远存在相同问题。上游可能继续演进。
